# Wrecked City

## How to play

Use the command buttons or type a command in the game box. Press Enter or click **Run** to use it.

### Start here

- `help` — See the commands.
- `status` — Check city health, resources, Ruin, and police response.
- `abilities` — See your moves and their costs.
- `npcs` — See people you can take over and their keys.
- `demo` — Watch a short example run.

### Make trouble

Spend Terror, Corruption, and Chaos to break the city's systems. Try a move with `cast`, for example:

```text
cast blackout
```

To use someone with power, find their key with `npcs`, then try:

```text
possess tech_ceo
exploit tech_ceo
```

Each move takes a turn. The city may repair damage, and the police response gets tougher as your threat rises. Check `status` often. Break the city to win; if the police catch you, the run ends.

### Saves and new runs

- `save` — Save your run in this browser.
- `load` — Load your browser save.
- `export` — Download a save file.
- `import` — Load a save file.
- `new` — Start a new run. Use `new 123` to pick a run number.

Your browser save stays in that browser. Use `export` to keep a separate copy.
